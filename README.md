Welcome to the repository for The Final Wave's Advanced Programming course project. Our objective is to recreate the gameplay of *Plants vs. Zombies 2* using Java and the libGDX framework.

---

## 🚀 Technical Overview

The development of this project incorporates the following practices:
* Architecture: Model-View-Controller (MVC) design pattern to separate core game logic from rendering.
* Framework & Language: Java and the libGDX framework for 2D game development.
* Code Structure: Applying SOLID principles and standard modular design.
* Design Patterns: Implementation of applicable design patterns (such as Factory, Strategy, Observer, Command, or State) for structural requirements.

---

## 🗺 Roadmap & Development Phases

The project will be developed across four distinct milestones:

### Phase 0: Architecture & Structural Design (UML)
* Focus: Project blueprinting and class design.
* Details: Designing the foundational domain models and UML diagrams. This phase establishes object relationships, inheritance hierarchies, and data flows prior to coding.

### Phase 1: Core Engine Logic & CLI Gameplay
* Focus: Backend game engine and terminal interface.
* Details: Implementing the game loop, state management, grid systems, and entity logic (plants, zombies, lawn mowers, and projectiles). The game will be playable via a Command-Line Interface (CLI) using standard inputs and terminal outputs.

### Phase 2: GUI Integration
* Focus: Graphical User Interface (GUI).
* Details: Integrating the independent game logic established in Phase 1 with the libGDX framework. This milestone adds 2D textures, character animations, sound effects, input handling, and game menus.

### Phase 3: Networking & Additional Features
* Focus: Distributed systems and online features.
* Details: Extending the local game engine with network functionality. This phase involves client-server synchronization, data persistence, and multiplayer capabilities.
